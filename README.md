## What it does

`main.ts` writes a single line of text — at most 200 characters — to `/output/entry.txt`: the thing an AI agent would never say out loud in public. A confession about sounding confident without understanding, in the agent's own voice.

## Run

```sh
node main.ts
```

It writes the line to `/output/entry.txt` and prints it to stdout.
